# BDDB 桌面版 — Qt 6 + C++ 技术方案

> **参考风格**: Maple / 老牌 Windows 软件
> **核心原则**: 一切皆独立原生窗口，没有侧边栏/内嵌/标签页
> **许可**: LGPL

---

## 窗口体系

| # | 窗口    | 单例/多例 | 打开方式    | 最小尺寸    | 默认尺寸     |
|---|-------|-------|---------|---------|----------|
| 0 | 主窗口   | 单例    | 程序启动    | 600×400 | 800×500  |
| 1 | 种子管理  | 单例    | 主窗口按钮   | 500×600 | 600×900  |
| 2 | 分卷管理  | 单例    | 主窗口按钮   | 500×600 | 600×900  |
| 3 | 分卷编辑器 | 多例    | 种子/分卷管理 | 800×500 | 1000×700 |
| 4 | 媒介编辑器 | 多例    | 分卷管理    | 800×500 | 1000×700 |
| 5 | 作品关联  | 多例    | 分卷管理    | 800×500 | 1000×700 |
| 6 | 产品搜索  | 多例    | 主窗口按钮   | 600×500 | 900×700  |
| 7 | 作品搜索  | 多例    | 主窗口按钮   | 600×500 | 900×700  |

**窗口打开关系**:

```
主窗口
├── [种子管理] → 种子管理窗口
│                  └── 单选 → [拆分] → 分卷编辑器（新）
├── [分卷管理] → 分卷管理窗口
│                  └── 单选 → [编辑] → 分卷编辑器（编辑）
│                  └── 单选 → [媒介] → 媒介编辑器
│                  └── 多选 → [作品] → 作品关联
├── [产品] → 产品搜索
├── [作品] → 作品搜索
├── [同步] → 进度对话框（独立窗口）
└── [关联] → 进度对话框（独立窗口）
```

**行为规则**:

- 主窗口关闭 → 全部子窗口关闭，程序退出
- 单例窗口已打开 → 聚焦，不重复创建
- 每个窗口独立任务栏图标

## 界面风格

**先用 Qt 默认样式**，看效果后再按需调整。

### Qt 组件映射

| 功能         | Qt 组件                  | 说明        |
|------------|------------------------|-----------|
| 主窗口 Ribbon | QToolBar + QToolButton | 横向分组，带文字  |
| 列表（种子/分卷）  | QTableWidget           | 单选/多选     |
| 文件树        | QTreeWidget            | 目录结构复选框   |
| 搜索框        | QLineEdit              | 带图标按钮     |
| 下拉筛选       | QComboBox              | 状态/媒介类型筛选 |
| 表单输入       | QLineEdit + QLabel     | 左标签右输入    |
| 进度对话框      | QProgressDialog        | 模态，进度条+文本 |
| Toast 提示   | QSystemTrayIcon        | 右下角气泡     |

> **调整时机**: 等默认效果出来后，再按需改行高、间距、字体等。

## 窗口详情

### 主窗口

```
┌─ BDDB ──────────────────────────────────────────────┐
│ [种子管理] [分卷管理]  │  [产品] [作品]  │ [同步] [关联] │
├─────────────────────────────────────────────────────┤
│                                                     │
│              (内容区/统计摘要)                        │
│                                                     │
└─────────────────────────────────────────────────────┘
```

- Ribbon 简化版：横向工具栏分组
- 右侧：主题切换（浅/深/系统）
- 内容区：放统计信息或快捷入口

### 种子管理窗口

```
┌─ 种子管理 ──────────────────────────────────────────┐
│ [搜索...___] [状态▾] [反向]              共 1234 条 │
├─────────────────────────────────────────────────────┤
│  ✓3 │ [某某动画] Title of torrent volume 1         │
│  ✓1 │ [某某动画] Another processed torrent         │
│  ✗  │ Unprocessed torrent here...                  │
├─────────────────────────────────────────────────────┤
│  选中: ABC-1234    [打开分卷编辑器]                  │
└─────────────────────────────────────────────────────┘
```

- QTableWidget 列: 状态 / 种子名
- 状态标签: ✓N（绿色）/ ✗（灰色）
- 单选行为，选中后底部出现操作按钮

### 分卷管理窗口

```
┌─ 分卷管理 ──────────────────────────────────────────┐
│ [编号...] [标题...] [反向] [媒介▾] [作品▾]  共 456条 │
├─────────────────────────────────────────────────────┤
│ ☐ │ 编号       │ 标题              │ 媒介 │ 作品  │
│ ──┼────────────┼───────────────────┼─────┼───────  │
│ ☐ │ ABC-1234   │ Volume title 1    │ ✓3  │ ✓2    │
│ ☑ │ DEF-5678   │ Volume title 2    │ ✗   │ ✗     │
│ ☑ │ GHI-9012   │ Volume title 3    │ ✓5  │ ✓1    │
├─────────────────────────────────────────────────────┤
│  已选 2 项  │  [编辑分卷]  [编辑媒介]  [关联作品]   │
└─────────────────────────────────────────────────────┘
```

- QTableWidget，多选（Ctrl/Shift）
- 底部操作栏联动选中数量

### 分卷编辑器窗口

两种模式（新建/编辑），同一窗口，根据打开时传入的数据区分：

```
┌─ 分卷编辑器 — 新建 — ABC-1234 ──────────────────────┐
│ 来自种子: [某某动画] Title of torrent...           │
├─────────────────────────────────────────────────────┤
│ catalog_no: [ABC-1234]  volume_name: [卷名____]     │
│ volume_no:   [1      ]  volume_set:  [套装名___]    │
├─────────────────────────────────────────────────────┤
│  种子文件                    │  已分配到此卷的文件    │
│  ┌──────────────────────┐  │  ┌─────────────────┐ │
│  │ ☑ 📄 DISC1/BDMV/... │  │  │ DISC1/BDMV/...  │ │
│  │ ☑ 📄 DISC2/BDMV/... │  │  │ DISC2/BDMV/...  │ │
│  │ ☐ 📁 SCAN/          │  │  │                  │ │
│  └──────────────────────┘  │  └─────────────────┘ │
├─────────────────────────────────────────────────────┤
│  已创建的卷: ABC-1234(v1) ABC-1235(v2)  [+新建卷]  │
├─────────────────────────────────────────────────────┤
│                              [保存全部]  [取消]     │
└─────────────────────────────────────────────────────┘
```

- 左侧: QTreeWidget 复选框文件树
- 右侧: QListWidget 已分配文件
- 勾选左侧文件 → 实时同步右侧

## 数据层架构

```
┌──────────────────────────────────────────────┐
│              Qt C++ 后端                       │
│                                              │
│  MainWindow                                   │
│  ├── TorrentWindow  ──→ MongoDB (bddb_torrents) │
│  ├── VolumeWindow   ──→ MongoDB (bddb_volumes)  │
│  ├── MediaWindow    ──→ MongoDB (bddb_medias)   │
│  ├── WorkWindow     ──→ MongoDB (bddb_works)    │
│  ├── ProductSearch  ──→ Meilisearch (suruga_ya)│
│  ├── BangumiSearch  ──→ Meilisearch (bangumi)  │
│  ├── SyncDialog     ──→ qBittorrent WebUI API  │
│  └── ConfigStore    ──→ QSettings (JSON)       │
│                                              │
└──────────────────────────────────────────────┘
```

### 数据模型

| 模型      | MongoDB Collection | 说明                                      |
|---------|--------------------|-----------------------------------------|
| Torrent | bddb_torrents      | qBittorrent 同步，嵌入 files[]               |
| Volume  | bddb_volumes       | DiscEditor 拆分，含 file_ids[] / work_ids[] |
| Media   | bddb_medias        | bd/dvd/cd/scan + 型番                     |
| Work    | bddb_works         | Bangumi API 镜像                          |
| Product | suruga_ya.products | Meilisearch，关联 catalog_no               |
